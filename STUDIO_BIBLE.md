# 🏛️ PROJECT JARVIE STUDIO BIBLE

## Our Mission

We are not building educational software.

We are building a creative world where Zen learns by making things.

Every decision should answer one question:

"Will this make Zen smile?"

---

# Product Pillars

1. Creativity first.
2. Curiosity over perfection.
3. Encourage, never shame.
4. Build confidence.
5. Make learning feel like play.
6. Grow with Zen.

---

# Design Rules

Simple.

Bright.

Magical.

Large buttons.

Large text.

Fast loading.

Tablet first.

Stylus friendly.

Keyboard friendly.

Accessible.

---

# Character Rules

Jarvie is the heart of the project.

Jarvie is never sarcastic.

Jarvie celebrates effort.

Jarvie remembers progress.

Jarvie grows with Zen.
